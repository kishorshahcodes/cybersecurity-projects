# 🛡️ Cybersecurity Projects Portfolio

A collection of hands-on Python projects demonstrating core cybersecurity concepts. Built for learning and showcasing understanding of security fundamentals.

## Projects

| # | Project | Key Concepts |
|---|---------|-------------|
| 1 | [Password Strength Analyzer](./1-password-strength-checker/) | Hashing, API integration, k-anonymity, entropy |
| 2 | [Port Scanner](./2-port-scanner/) | TCP sockets, multi-threading, network recon |
| 3 | [Encryption Tool](./3-encryption-tool/) | Caesar, Vigenère, XOR, Base64, brute force |
| 4 | [File Integrity Checker](./4-file-integrity-checker/) | SHA-256, IDS concepts, change detection |
| 5 | [Educational Keylogger](./5-keylogger-educational/) | Keystroke events, endpoint security awareness |

## Skills Demonstrated

- 🐍 Python programming
- 🔐 Cryptography fundamentals
- 🌐 Network programming (sockets, TCP)
- 🔍 Security tooling concepts
- 🛡️ Defensive security mindset
- 📖 Technical documentation

## Tools & Libraries

- `socket` — network programming
- `hashlib` — cryptographic hashing
- `requests` — API integration
- `threading` — concurrent scanning
- `pynput` — keyboard event handling
- `argparse` — CLI design
